# 위기관리 신호등

리스크관리부를 위한 **외부 경제지표 자동 모니터링과 AI 월간 리스크 보고서 초안** 서비스입니다.
지표를 사이트마다 찾아 옮겨 적던 일을 줄이고, 임계점을 넘은 지표를 바로 보여 주며, 판정 결과로 보고서 초안을 만들어 담당자가 검토·수정합니다.

> ⚠️ 실습용 앱입니다. 직접 입력 지표에는 실제 사내 수치 대신 **가상 값**만 사용합니다. 로그인이 없으므로 배포 주소를 외부에 공유하지 않습니다.

## 주요 기능

### 1. 지표 현황 (`/`)
- 22개 지표를 **거시경제(2) · 조기경보(12) · 위기대응(8)** 3개 분류로 보여 줍니다.
- 화면을 열면 공개 API에서 새 값을 수집해 저장소에 쌓고, **5년 평균 ± 표준편차** 또는 **기준값 × 비율** 산정식으로 임계점을 계산해 판정합니다.
- 분류마다 판정 단계가 다릅니다: 거시경제 정상/주의, 조기경보 정상/경계, 위기대응 정상/주의/경계/위기.
- 매월 **전월분**(분기 지표는 마지막으로 끝난 분기)을 기준으로 보고, 아직 발표되지 않았으면 **"발표 전"**과 직전 값을, 수집에 실패하면 **"수집 실패, 직전 값 기준일 ○○"**을 보여 줍니다.
- 자동 수집이 연결되지 않은 지표는 실습용 가상 값으로 표시하고 "가상 값"이라고 적습니다.

### 2. 직접 입력 (`/input`)
- 공개 API가 없는 위기대응지표(사내 데이터)를 매월 입력합니다. 목표값·담보가치 같은 기준값도 함께 넣고, 숫자·기준값·기간을 저장 전에 검사합니다.

### 3. AI 보고서 초안 (`/report`)
- 판정 결과를 분류별로 AI에 넘겨 "변동 요약 · 지표별 리스크 수준 · 외부 통계로 본 시사점 · 대응 제언" 초안을 만듭니다. 시사점은 수집한 공개 통계의 5년 평균·범위 안 위치·전년 대비·최근 추세를 근거로 씁니다. AI는 판정을 바꾸지 않고, 입력에 없는 수치나 투자 권유, 전망을 쓰지 않습니다.
- 담당자가 분류별로 고쳐 저장하고, 전체 리스크 수준은 담당자가 직접 고릅니다.
- "다시 만들기"는 담당자가 고친 섹션을 건드리지 않습니다. 같은 달에 다시 만들면 새 차수(2차, 3차…)로 저장합니다.

### 4. 지표 비교 (`/compare`)
- 지표 하나를 골라 최근 3년 값을 그래프(임계점 점선, 단계 색)와 같은 달 연도별 표(전년 대비)로 비교합니다.

### 5. 지표 업데이트 메일 알림
- 매주 월·금 오전 9시(한국 시간)에 지표를 수집하고, 지난 알림 이후 새로 발표된 공개 통계 값이 있으면 담당자 사내 메일로 요약을 보냅니다. 단계가 바뀐 지표는 맨 위에 강조합니다.
- 사내 데이터(직접 입력 지표)와 가상 값은 메일에 넣지 않습니다. 실행 주소는 `CRON_SECRET`으로 잠겨 있습니다.

## 데이터 출처

| 출처 | 지표 |
|---|---|
| 한국은행 ECOS | BSI, 은행 연체율, KOSPI, 원/달러 환율, 신용스프레드, 소비자심리지수, 기업경기실사지수 |
| 금융감독원 FISIS | 고정이하여신비율 4종 (국내은행 합계로 계산) |
| 한국부동산원 R-ONE | 지가지수 |
| KOSIS | 아파트 매매 실거래가격지수(한국부동산원), 소상공인 경기전반 전망, 중소기업 경기동행종합지수 |
| 직접 입력 | 위기대응지표 8개 (실습은 가상 값) |

## 기술 스택

| 도구 | 역할 |
|---|---|
| Next.js 16 (App Router) | 화면과 서버 API |
| Supabase | 지표 값·보고서 저장 |
| OpenAI API | 보고서 초안 작성 (실습 단계. 실제 업무에서는 사내 AI로 교체) |
| Zod | 입력값 검사 |
| Vitest | 판정 계산 자동 채점 |
| Tailwind CSS | 화면 꾸미기 |

## 실행 방법

```bash
npm install
npm run dev        # http://localhost:3000
npm test           # 판정·수집·검사 테스트
npm run db:check   # 저장소 연결 확인
npm run ai:check   # OpenAI 연결 확인
```

`.env`에 필요한 값: `SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY`, `OPENAI_API_KEY`, `OPENAI_MODEL`, `ECOS_API_KEY`, `FISIS_API_KEY`, `REB_API_KEY`, `KOSIS_API_KEY`
저장소 표는 `supabase/schema.sql`로 만듭니다. `.env`는 저장소에 올리지 않습니다.
